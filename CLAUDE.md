## Testing Deluge behaviour

Drive the emulator through the Python interface in `pylib/delugemu`
(`DelugeSession`: `launch`, `load_song("/SONGS/...")`, `press`, `turn`, `pad`,
`type_text`, `wait_sd_idle`, `read_oled`, `assert_no_aborts`), not hand-rolled
QMP key sequences. See README.md, "Testing Deluge issues programmatically", and
docs/scripting.md. The default SD image has bug-repro songs under
`SONGS/problem_songs/`.
